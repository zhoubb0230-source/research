# 产业机会经纬线：闸门规则与评分卡

> **用途**：把六条经纬线翻译成可复现、可跨行业比较的判定规则，供 `business-insight-solution-0001` 的专家团执行。
> **机器可读版**：`../assets/expert-team/rubric/rubric-v1.yaml`（**执行以 YAML 为准**，本文是它的说明与依据）
> **标记约定**：【设计】设计主张；【判断】推断；【待定】需业务侧输入。
> **状态说明**：`draft`。所有权重与阈值为**初始建议值**，必须经业务专家校准后冻结为 `rubric-v1` 才可用于正式筛选。本文不含任何产业数据。

## TL;DR

- **两段式**：先过闸（Gate，一票否决），再加权打分（Score，排序）。把"能力重合"和"管制"这类门槛塞进加权公式，会让做不了的机会冒到榜首。
- **毛利 50% 看的是在位头部玩家，不是我们。** 新进入者第一代产品做不到 50% 毛利，用它当准入门槛等于筛掉全部真实机会；它的正确含义是"这个行业的结构允许高毛利"。
- **"两强格局"不是恒定负分。** 两强不受管制 = 最差；两强均受对华管制 = 最好。竞争格局必须与管制不对称性联合判定。
- **"中国三年内无法突破"是自相矛盾的表述**，应重述为"突破周期 2–5 年"：短于 2 年壁垒不足，长于 5 年超出商业窗口。
- **数据缺失不淘汰。** 否则系统会系统性偏向数据公开充分的成熟行业——而那里机会最少。缺数据的机会进"待补证池"，不参与本轮排名。

## 1. 两段式结构【设计】

```
候选机会
   │
   ├─▶ Gate 闸门（6 条，任一不过即出局，记录理由进出局池）
   │      G-1 能力可迁移  G-2 技术成熟度  G-3 我方可造性
   │      G-4 法律合规    G-5 红海排除    G-6 数据可得性（特殊：不淘汰，转待补证池）
   │
   ├─▶ Score 加权（6 维，各 0–10 分，加权求和 100 分制）
   │      A 技术链重合 25 │ B 客户结构 18 │ C 市场与盈利 20
   │      D 竞争格局 15   │ E 政策战略 12 │ F 技术窗口 10
   │
   ├─▶ Adjust 修正（3 项，各 ±10 分）
   │      g 进入路径 │ h 验证成本 │ i 管制不对称
   │
   └─▶ 双维排序：终分 × 置信度
```

**为什么闸门要在打分之前**：闸门判定成本极低（多数是规则或单点检索），打分成本极高（要对 6 个维度全面取证）。闸门后置会让 P3 取证阶段的成本高一个量级【判断】。

## 2. 闸门规则（Gate）

| ID | 闸门 | 判定 | 出局理由 |
|---|---|---|---|
| **G-1** | 能力可迁移性 | A 维度得分 < 4 | 与现有技术链无实质重合，本质是从零开始的新公司 |
| **G-2** | 技术成熟度 | TRL < 5（仍在概念/实验室原型阶段） | 原构想 f 明确要求"完成了泡沫破灭期的原型机"，概念期项目不在范围 |
| **G-3** | 我方可造性 | 核心部件/材料受进口管制且无国内替代与自研路径 | 造不出来的机会不是机会 |
| **G-4** | 法律与合规红线 | 军品、受限终端用途、明令禁止或淘汰类产业 | 一票否决，无例外 |
| **G-5** | 红海排除 | 全球有效供应商 > 20 家 且 头部毛利 < 30% | 已充分竞争，不满足"价利双高"前提 |
| **G-6** | 数据可得性 | A/C/D 三维的核心指标全部 `NA` | **不出局**：转入「待补证池」，本轮不排名，下一轮定向补采后重评 |

**G-6 的设计理由【设计】**：把"查不到数据"当淘汰条件，会让系统系统性偏向统计口径完善的成熟行业。而按经纬线 f 的逻辑，最好的机会恰恰出现在细分、新兴、公开数据稀薄的地方。数据缺失是**我们的信息问题**，不是**机会的质量问题**，两者必须分开处理。

**出局池必须留档**：每个出局机会记录 `触发闸门 + 判定依据 + evidence_ref + 判定日期`。下一轮重跑时先复检出局池——闸门阈值调整或新证据出现都可能翻案。

## 3. 评分维度与锚点

每个维度 0–10 分，**必须命中锚点表中的具体一档并写明理由**，禁止给"感觉分"。无法判定写 `NA`（不计入分母，同时降低置信度）。

### 3.1 A · 技术链重合度（权重 25）

对应经纬线 a。**不给整体印象分**，拆成子能力项逐项判定：

| # | 子能力项 | 说明 |
|---|---|---|
| 1 | 超高真空与气体/流体控制 | 真空腔体、泵组、质量流量控制 |
| 2 | 精密运动与定位 | 气浮/磁浮、直线电机、纳米级伺服与隔振 |
| 3 | 光机电一体化与精密光学 | 光路设计、镜组装调、光学对准 |
| 4 | 超净与污染控制 | 颗粒控制、材料相容性、出气管理 |
| 5 | 射频/高压电源与等离子体 | 电源、匹配网络、放电控制 |
| 6 | 在线量测与传感 | 光学/电学/成像量测、原位监测 |
| 7 | 过程控制软件 | 配方管理、APC/FDC、数据链路 |
| 8 | 高可靠性与量产工程 | MTBF、24/7 连续运行、备件与服务体系 |
| 9 | 精密供应链 | 精密加工、陶瓷/石英、特种密封与传动 |
| 10 | 客户工艺协同 | 与终端客户共同调试工艺窗口的组织能力 |

**锚点**

| 分 | 判定标准 |
|---|---|
| 10 | ≥6 项直接复用，且该业务的核心技术难点正落在我方现有强项上 |
| 8 | 4–5 项直接复用 |
| 6 | 3 项直接复用，或 5 项需中度改造 |
| 4 | 2 项直接复用，或多项需重度改造 |
| 2 | 仅 1 项，且属通用能力（如一般机械加工） |
| 0 | 无实质重合 |

> ICT/AI 方向的重合按同样方式拆：算法与数据链路、嵌入式与实时控制、工业软件、边缘算力、模型工程与数据闭环。由 S4 技术链分析师维护子能力项清单并版本化。

### 3.2 B · 客户结构与直销适配（权重 18）

对应经纬线 b。**关键口径**：评的是**设备采购方**的集中度，不是终端行业的集中度。

原构想的 b 与 c 存在内在张力：1000 亿级的终端行业客户往往分散。解法是把观察层从"终端行业"下沉到"设备采购方"——终端行业可以很大很分散，但买这台设备的可能只有几十家【设计】。

| 分 | 判定标准 |
|---|---|
| 10 | 全球目标客户 < 30 家；Top10 客户占行业设备采购 > 60%；可直接触达技术决策人 |
| 8 | 客户 < 100 家；Top10 > 40%；直销可覆盖 |
| 6 | 客户 100–300 家；需少量区域服务点 |
| 4 | 客户 300–1000 家；需渠道分销 |
| 2 | 客户 > 1000 家；必须建经销体系 |
| 0 | 面向消费端或长尾市场 |

### 3.3 C · 市场规模、增长与盈利结构（权重 20）

对应经纬线 c。原构想给的门槛：行业 1000 亿 / 设备 100 亿 / CAGR 15% / 毛利 50%。

**口径修正一【设计】：毛利 50% 指的是「在位头部玩家的毛利率」，不是我方目标毛利。**
新进入者的第一代产品几乎不可能有 50% 毛利。这条指标的真实信息量是"**该行业的结构允许高毛利**"（技术壁垒高、客户按价值付费、不是成本竞争）。当成我方准入门槛用，会筛掉全部真实机会。

**口径修正二【设计】：四个门槛不是与关系，而是分档锚点。**
四条全达标的机会极稀少；全达标才进榜会导致空榜。

| 分 | 判定标准 |
|---|---|
| 10 | 设备市场 ≥ 200 亿 且 CAGR ≥ 20% 且 在位头部毛利 ≥ 55% |
| 8 | 设备市场 ≥ 100 亿 且 CAGR ≥ 15% 且 在位头部毛利 ≥ 50%（= 原构想门槛全达标） |
| 6 | 上述三项中达标两项 |
| 4 | 达标一项 |
| 2 | 均未达标，但三项指标均在向上趋势中 |
| 0 | 市场萎缩，或行业毛利结构性偏低（头部 < 30%） |
| NA | 设备市场规模或毛利数据缺失且不可得 |

**数据可得性提示【判断】**：终端行业规模在统计部门口径中通常可查；**设备级细分市场规模（100 亿这一层）在官方统计里一般查不到**，需依赖行业协会、上市公司分部披露、招股说明书的市场章节。这是本维度 `NA` 率最高的地方，取证时应优先攻这一项。

### 3.4 D · 竞争格局（权重 15）

对应经纬线 d。**必须与修正项 i（管制不对称）联合判定**。

| 分 | 判定标准 |
|---|---|
| 10 | 全球有效供应商 3–8 家；无绝对双强（CR2 < 60%）；且主要在位者受对华出口管制 |
| 8 | 供应商 3–10 家；CR3 < 70% |
| 6 | 供应商 ≤ 10 家；CR3 70–85% |
| 4 | 双强格局（CR2 > 70%），但属规模型双强（技术无代差） |
| 2 | 双强格局，属技术垄断型（存在代差 + 专利/生态壁垒） |
| 0 | 单一垄断且专利与生态双重封锁 |

**"两强优先级放低"需要打的补丁【设计】**：原构想把"有两强"一律降优先级。但双强格局的含义取决于两件事——
1. **是规模型双强还是技术垄断型双强**：前者可攻（靠成本、服务、本地化），后者难攻（有代差）。
2. **两强是否受对华管制**：若两强均受管制且无替代供给，则国内需求侧被强制腾出空间。**这是最好的机会，不是最差的。**

因此双强不直接降级，而是走 D=4 或 D=2，再由修正项 i 加回（最高 +10）。

### 3.5 E · 政策与战略契合（权重 12）

对应经纬线 e。

| 分 | 判定标准 |
|---|---|
| 10 | 同时命中新兴产业目录与单体设备攻关/首台套类目录，且尚无被指定独家承担的国家队 |
| 8 | 命中其中之一，且有明确专项支持 |
| 6 | 属鼓励类，但无对应专项 |
| 4 | 无明确政策定位（中性） |
| 2 | 属限制类 |
| 0 | 属淘汰类或禁止类 |

**修正 −3**：若该方向已有政策指定的独家承担主体。**"在攻关目录里"是双刃剑**——它既意味着国家资源与订单确定性，也意味着竞争者可能是被指定的【设计】。这一点原构想未覆盖。

> 政策文件的判定必须回原文并给出文件名 + 发布机构 + 条目定位，禁止凭记忆（见 solution-0001 §1.1 铁律四）。

### 3.6 F · 技术窗口与国产化缺口（权重 10）

对应经纬线 f。原表述"技术发展完成了泡沫破灭期的原型机（中国三年内大概率无法突破）"包含一个**自相矛盾**：如果中国三年内大概率无法突破，作为一家中国公司我们同样突破不了。

**重述【设计】**，拆成三个可判定子项：

| 子项 | 含义 | 目标区间 |
|---|---|---|
| **TRL 成熟度** | 技术已被验证可行，但尚未商品化 | TRL 6–8。< 5 是概念期（G-2 出局）；= 9 且已白菜化则无溢价 |
| **国产化率** | 进口依赖程度 | < 30% 为佳。> 70% 说明已充分国产化，窗口关闭 |
| **突破周期** | 从投入到形成可交付产品所需时间 | 2–5 年。**< 2 年壁垒不足**（同行会迅速跟上）；**> 5 年超出商业窗口** |

"三年内无法突破"的真实意图是**壁垒要足够高**，高到我们突破之后同行不会在一年内跟平——这是护城河要求，不是不可行性要求。

| 分 | 判定标准 |
|---|---|
| 10 | TRL 6–8 + 国产化率 < 10% + 突破周期 3–5 年 |
| 8 | TRL 6–8 + 国产化率 < 30% + 突破周期 2–5 年 |
| 6 | 满足上述三子项中的两项 |
| 4 | 满足其一 |
| 2 | 国产化率 > 70%（窗口已关闭）或突破周期 < 2 年（壁垒不足） |
| 0 | TRL < 5（已由 G-2 拦截，此处冗余保护） |

**"泡沫破灭期"的价值【判断】**：Gartner 曲线的幻灭低谷期具备三个特征——估值回落、投机者退出、但技术仍在稳步推进。在这个时点进入，竞争强度与获取成本都处于低点，而技术风险已被前一轮泡沫替我们验证过。这是原构想里最有洞察力的一条，应完整保留。

## 4. 修正项（各 ±10）

修正项是对原构想 a–f 的补充：a–f 回答"这个机会值不值得做"，修正项回答"**我们能不能进得去、进去要付多少代价**"。

### 4.1 g · 进入路径可得性

| 分 | 判定标准 |
|---|---|
| +10 | 存在可并购/可投资标的 **且** 有明确灯塔客户联合开发意向 |
| +5 | 具备其中之一 |
| 0 | 无现成路径，但可自建团队进入 |
| −5 | 关键人才或核心供应链不可得 |
| −10 | 存在专利封锁，或必要资质/认证在可预见期内无法获得 |

**没有进入路径的机会不是机会，是新闻。**【设计】原构想六条经纬线全是"标的属性"，没有一条是"我方可及性"，这是最大的结构性缺口。

### 4.2 h · 验证成本与周期

| 分 | 判定标准 |
|---|---|
| +5 | 首台套验证周期 < 12 个月，NRE 投入在常规项目量级 |
| 0 | 验证周期 12–24 个月 |
| −5 | 验证周期 24–36 个月 |
| −10 | 验证周期 > 36 个月，或需客户产线长期停机配合 |

装备类新业务的隐性成本主要在验证阶段，而且它直接决定了**可承受的试错次数**——三年一次试错的赛道，容错率与一年一次的完全不同【判断】。

### 4.3 i · 管制不对称性

**双向判定，两个方向分别取值后求和**（合计钳制在 ±10）：

| 方向 | 分 | 判定标准 |
|---|---|---|
| 向内（机会侧） | +10 | 在位供应商全面受对华出口管制，且国内无替代供给 |
| | +5 | 部分受限，或存在许可证不确定性 |
| | 0 | 无管制影响 |
| 向外（我方侧） | −5 | 我方产品部分落入管制清单，影响出口或技术合作 |
| | −10 | 核心部件受进口管制且无替代（**同时触发 G-3 闸门**） |

判定要求：管制类判定必须给出**清单名称 + 版本/生效日期 + 类别号或条目号 + 检索日期**，三态输出 `restricted` / `not_restricted` / `undetermined`，**`undetermined` 不得被当作 `not_restricted` 使用**。详见 solution-0001 §4。

> 本系统的管制判定仅为内部研判输入，**不构成合规意见**，最终以法务/合规部门结论为准。

## 5. 计分与排序

### 5.1 终分

```
基础分 = Σ (维度权重 × 维度得分 / 10)          # 0–100
终分   = 基础分 + g + h + i                     # 理论范围 −30 ~ 130

NA 处理：该维度不计入分子，权重从分母中扣除后归一化
        （即 NA 不当 0 分，避免"查不到"被误判为"很差"）
```

### 5.2 置信度（与终分同等重要）

```
置信度 = f(证据覆盖率, 平均证据等级, 冲突证据数, 红队推翻数)

  证据覆盖率 = 已 verified 的核心指标数 / 核心指标总数
  平均证据等级 = A 级计 3、B 级计 2、C 级计 1 的加权平均

high   : 覆盖率 ≥ 80% 且 平均等级 ≥ 2.0 且 无 conflicting 且 红队未推翻核心结论
medium : 覆盖率 60–80%，或存在已仲裁的 conflicting
low    : 覆盖率 < 60%，或存在 undetermined 的管制判定，或红队推翻了 ≥1 项核心结论
```

### 5.3 排序规则【设计】

**双维排序，不做单一维度的线性排名。**

1. 先按置信度分层：`high` / `medium` / `low` 三层。
2. 层内按终分降序。
3. **`low` 置信度的机会，无论终分多高，都不得直接进入 Top K 深度洞察**——先走定向补证，补到 `medium` 以上再重排。

理由：一个 110 分但置信度 `low` 的机会，最可能的解释不是"它真的很好"，而是"缺失的数据恰好被乐观填充了"【判断】。把它直接送进深度洞察，等于把资源投给系统自己最不确定的东西。

### 5.4 榜单必备列

| 列 | 说明 |
|---|---|
| 排名 / 机会名称 | |
| 终分 / 置信度 | 双维 |
| 六维分值 | 逐维列出，便于看清得分结构 |
| 修正项 g/h/i | 分别列出 |
| **选择理由** | 3–5 句，每句必须带 `evidence_ref`（对应原构想"每个机会后面附上选择该机会的原因"） |
| **最可能错在哪** | 红队给出的头号致命假设（**这一列不可省略**） |
| 证据覆盖率 | 百分比 |
| 管制状态 | 向内/向外双向，三态 |
| rubric 版本 | 保证跨批次可比 |

**"最可能错在哪"必须与"选择理由"并列呈现。**【设计】只列理由不列风险的榜单，会被读者当成推荐清单而不是研判输入。

---

## 6. 口径校准（P0，不可跳过）

rubric 定稿前必须做一致性校准：

1. 选 5 个已知机会（含 2 个业务侧公认的好机会、2 个公认的坏机会、1 个有争议的）。
2. 3 名业务专家独立用 rubric 打分。
3. 逐维度计算分差。**任一维度分差 > 2 分，说明该维度的锚点描述有歧义，必须重写锚点而不是调权重。**
4. 同时让专家团跑一遍同样 5 个机会，对比人机分差——**人机分差大的维度，是模型最需要领域知识包的地方**。
5. 校准通过后冻结为 `rubric-v1`，写入版本号与冻结日期。**一轮筛选中途不得改口径。**
