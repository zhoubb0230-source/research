# 证据卡填写指引

机器可读定义见 `../schemas/evidence.schema.json`。本文是给人看的填写说明与自检清单。

## 一条证据卡回答什么

> **谁**（来源）在**什么时候**（发布日期）用**什么口径**（scope + period + unit）说了**什么数**（value），**在哪一页**（locator）。

六项缺一，这条证据就不能进评分。

## 字段填写要点

| 字段 | 要点 |
|---|---|
| `claim` | 一句话说清这条证据支撑什么断言。写不清楚说明取证目标不明确，回去问 |
| `value.raw` | **来源中的原始表述，不做任何换算**。"1,240" 就写 "1,240" |
| `value.normalized` | 换算后的数。换算规则（含汇率与汇率日期）写进 `note` |
| `value.scope` | 全球 / 中国大陆 / 某细分范围。**最容易出错也最致命的字段** |
| `value.period` | 年份；预测值必须带 E，如 `2025-2030E` |
| `verbatim` | 原文摘录。管制类与政策类证据**必填** |
| `source.grade` | A/B/C/D，见下 |
| `source.locator` | 页码 / 表号 / 章节 / 条目号。**填不出就是 `unverified`** |
| `cross_sources` | C 级来源必填，且必须是**独立**来源——同一机构的两份报告不算独立 |

## 证据等级

| 等级 | 来源 | 可用性 |
|---|---|---|
| **A** | 官方统计、海关、上市公司年报/招股说明书、政府规划与目录文件、专利数据库 | 直接可用 |
| **B** | 行业协会与标准组织公开数据、权威行业年鉴 | 直接可用 |
| **C** | 券商研究、第三方咨询报告 | 需 ≥1 条独立交叉来源 |
| **D** | 媒体报道、厂商宣传、社区讨论 | **永不入表**，只作线索去追 A/B 级原始来源 |

## 提交前自检

- [ ] `scope` 写死了吗？全球和中国大陆没混？
- [ ] 要的是**设备市场规模**还是终端行业规模？没搞混？
- [ ] `period` 是历史值还是预测值？预测值标 E 了吗？
- [ ] 毛利率取的是**产品线分部披露**还是公司整体？
- [ ] 单位与汇率记录了吗？汇率日期呢？
- [ ] `locator` 能让核证官在 1 分钟内定位到吗？
- [ ] 这个数是不是从 D 级材料抄来的？追到原始来源了吗？
- [ ] 有没有把多个来源"平均一下"？（禁止——多源不一致是 `conflicting`）
- [ ] 有没有在任何字段里写"约""预计""大致"？（禁止）
