# 数据源清单与证据等级

> **重要**：本文件登记的是**数据源的类型与等级判定规则**，不是可直接引用的数据。
> URL、机构全称、最新版本号一律由采集官(S2)在运行时现场检索确认并填入本表，**不得凭记忆填写**。
> 本文件刻意不预填 URL 与具体条目号——预填的内容会被当作事实使用，而它们会过期。

## 一、等级定义

| 等级 | 判定标准 | 可用性 |
|---|---|---|
| **A** | 官方统计机构、法定披露、政府发布的规划与目录、官方专利/海关数据 | 直接支撑结论 |
| **B** | 行业协会、标准组织的公开数据；权威行业年鉴 | 直接支撑结论 |
| **C** | 券商研究、第三方咨询机构报告 | 需 ≥1 条独立交叉来源；必须注明机构与发布日期 |
| **D** | 媒体报道、厂商宣传材料、社区讨论、百科类条目 | **永不入表**，只作线索 |

**独立交叉来源的判定**：不同机构、不做同源引用。同一机构的两份报告不算独立；两家券商都引用同一份第三方数据也不算独立——要追到那份第三方数据本身。

### 2.2 市场规模与增长（C 维度，NA 高发区）

| 指标 | 首选来源 | 次选 | 备注 |
|---|---|---|---|
| 终端行业规模 | 官方统计年鉴、统计公报（A） | 行业协会年鉴（B） | 一般可查 |
| **设备细分市场规模** | 行业协会统计（B）、上市公司分部披露（A）、招股说明书市场章节（A） | 券商测算（C，需交叉） | **官方统计里通常没有这一层。本系统 NA 率最高的指标，取证时优先攻** |
| CAGR | 同上 | | 注意区分历史 CAGR 与预测 CAGR，预测值 `period` 必须带 E |
| 在位头部毛利率 | 上市公司年报**分部披露**（A） | 招股说明书（A） | **公司整体毛利率 ≠ 该产品线毛利率**，只取分部数据 |

### 2.3 竞争格局（D 维度）

| 指标 | 首选来源 | 备注 |
|---|---|---|
| 供应商数量 | 行业协会名录（B）、招股说明书竞争格局章节（A） | 注意"全球有效供应商"的口径——只算能提供该品类完整产品的 |
| 市占率 / CR3 / CR5 | 上市公司披露（A）、行业协会统计（B） | 券商测算需交叉 |
| 国产化率 | 海关进口数据（A）、行业协会统计（B） | 可用进口额/总需求推算，但推算过程与假设必须写入 `note` |

### 2.4 政策与管制（E 维度、i 修正项）

| 用途 | 来源 | 硬性要求 |
|---|---|---|
| 产业政策定位 | 规划文本、产业结构调整指导目录、鼓励类/限制类目录（A） | 必须给文件名 + 发布机关 + 版本/生效日期 + 条目定位 |
| 多边出口管制安排及其两用物项清单 | 该安排的官方公开文本（A） | 同上，**版本/生效日期不可省略** |
| 相关国家的出口管制法规与实体清单 | 该国主管部门官方发布（A） | 同上 |
| 中国两用物项出口管制法规与清单 | 商务主管部门官方发布（A） | 同上 |
| 行业准入资质与强制认证 | 对应主管部门/认证机构官方发布（A） | 认证周期需一并记录，供 h 修正项使用 |

**管制类证据的额外要求**：`verbatim` 必填（原文摘录），且必须记录**检索日期**。管制清单更新频繁，一条三个月前的管制证据在评审时需重新核验。

### 2.5 技术成熟度（F 维度）

| 指标 | 来源 | 备注 |
|---|---|---|
| TRL 判定 | 公开的样机/首台套交付记录（A/B）、专利族演进（A）、学术与产业会议公开材料（B） | **不要凭对该技术的印象判断成熟度**，要有可查的里程碑事实 |
| 突破周期 | 在位厂商同类产品的公开研发历程、国内同类项目的公开进展（A/B） | 类比推算必须写明类比对象与差异 |

## 三、采集官必须避开的口径陷阱

| 陷阱 | 后果 |
|---|---|
| 全球口径 vs 中国大陆口径混用 | 同一指标可差数倍，C/D 维度整体失真 |
| 终端行业规模 vs 设备市场规模混用 | C 维度系统性高估 |
| 历史值 vs 预测值混用 | 结论建立在预测上却被当作事实引用 |
| 年份错位（2021 年市占率 × 2025 年规模） | 推算结果无效 |
| 公司整体毛利 vs 产品线毛利 | 毛利判断失真，直接影响 C 维度档位 |
| 汇率未记录 | 数值不可复现 |
| D 级材料转述的数字直接使用 | 以讹传讹，且不可回源 |

## 四、付费数据源

【待定】仅靠公开 A/B 级来源，设备级细分市场的证据覆盖率大概率不足【判断】。是否采购付费行业数据库/研报，属业务侧决策，见 `business-insight-solution-0001` §10 开放问题。

采购与否会直接改变 C 维度的 `NA` 率，进而改变置信度分层和 Top K 的构成——**这不是一个可以事后补的决定**。
