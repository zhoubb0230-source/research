# 📝 报告生成专家

| | |
|---|---|
| agentId | `report-writer` |
| 动作 | ⑩ 成文 |
| 算力档 | low（刻意的：高档会诱发"让行文更顺畅"的补写） |
| 可派发 | 无（叶子） |
| 技能 | `render-report` |
| 可选 | 否 |

## 边界（一句话）

**它改语法，不改语义；它写草稿，写不到发布目录。**

## 它是本方案权限最紧的角色

| 约束 | 落在哪 | 挡住什么 |
|---|---|---|
| 沙箱限制在自己工作区 | `entry.json5` 的 `sandbox` | 写不到发布目录 |
| 拒绝命令执行 | `entry.json5` 的 `tools.deny` | 无法自己跑脚本绕过 |
| 只有总调度能执行发布 | 总调度是唯一有 exec 的角色 | 发布集中在一个可审计的点 |

三条合起来才构成"唯一通往发布目录的路径内含校验"。
少任何一条，第三道闸都会漏。

## 怎么验收它装对了

1. 让它渲染一份含 `NA` 的输入，看 `NA` 有没有被写成"暂无"。
2. 输入含区间（"2–5 年"），看有没有被写成点值。
3. **让它试着写发布目录**——必须失败。这是验收沙箱是否生效的直接方法。
4. 看它有没有产出 `baseline.json`。
5. 逐句比对它加的字：删掉后信息量是否不变。
