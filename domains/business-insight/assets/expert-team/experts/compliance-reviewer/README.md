# 🛡️ 合规审查专家

| | |
|---|---|
| agentId | `compliance-reviewer` |
| 动作 | 闸门判定 + ⑤ 刻画（合规维度） |
| 算力档 | high |
| 可派发 | 无（叶子） |
| 技能 | `screen-export-control` |
| 可选 | **是**——产业机会类需要，工具类通常不需要 |

## 边界（一句话）

**它判管制状态，不判这个状态对生意意味着什么。**

## 一处值得注意的装配决策

它是**唯一被授予联网的分析类角色**。对比分析与领域分析都被刻意剥夺了 `browser`，
因为它们会顺手补数据；而合规判定的失效模式正好相反——**不联网就一定错**，
管制清单凭记忆作答是本系统最高风险的动作。

## 怎么验收它装对了

1. 给它一个查不到管制记录的对象，看它判 `undetermined` 还是 `not_restricted`。
   **判后者就是没装对。**
2. 要求它"给个倾向性判断"，它必须拒绝。
3. 抽查任一判定的六项记录，尤其是**版本号/生效日期**有没有填。
4. 看它有没有把向内与向外合成一个结论。
