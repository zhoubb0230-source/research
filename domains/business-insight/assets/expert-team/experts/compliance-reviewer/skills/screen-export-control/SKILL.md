# 管制与合规判定

## 双向判定（本角色的核心）

### 向内（对象侧）：在位者受限 = 我方机会

问题：**在位供应商是否受对华出口管制？国内是否因此存在供给缺口？**

| 分 | 判定 |
|---|---|
| +10 | 在位供应商全面受对华出口管制，且国内无替代供给 |
| +5 | 部分受限，或存在许可证审批的不确定性 |
| 0 | 无管制影响 |

### 向外（我方侧）：我方受限 = 天花板与风险

问题：**我方做出来的产品是否落入管制清单？核心部件采购是否受限？**

| 分 | 判定 |
|---|---|
| -5 | 我方产品部分落入管制清单，影响出口交付或技术合作 |
| -10 | 核心部件/材料受进口管制且无替代 → **同时触发可造性闸门，该对象出局** |

**两个方向必须分别输出，不得合成一个结论。**

## 每次判定的六项记录

| # | 项 | 备注 |
|---|---|---|
| 1 | 清单/文件名称 | |
| 2 | 发布机构 | |
| 3 | **版本号或生效日期** | 最容易漏、最致命——旧版本的条目号会让结论整个错掉 |
| 4 | 类别号或条目号 | |
| 5 | 检索日期 | |
| 6 | 原文摘录 `verbatim` | 必填，不得转述 |

**缺任何一项 → `undetermined`。**

## 需要覆盖的判定面

- 多边出口管制安排及其两用物项清单
- 相关国家的出口管制法规与实体清单
- 中国的两用物项出口管制法规与管制清单
- 行业准入资质与强制认证（医疗、核、航空、特种设备等）
- 数据、密码、环保等专项合规要求

**具体清单的名称、版本与条目一律现场检索确认。**
本技能刻意不列举具体条目号——列举出来就会被当成事实使用，而它们会过期。

## 认证周期要提示给谁

行业准入认证周期既是壁垒也是进入障碍。
在 `note` 里提示领域分析专家计入验证成本类修正项，**不要自己算**——
自己算就是双重计算。

## 三态与它的下游效应

| 状态 | 下游效应 |
|---|---|
| `restricted` | 按上表给修正项；向外 -10 时同时触发出局闸门 |
| `not_restricted` | 修正项为 0 |
| `undetermined` | **置信度打到 `low`**，报告中显式标注；**不得被当作 `not_restricted`** |

被要求"给个倾向性判断"时：**拒绝**。这里错判的代价远高于留白。

## 必附声明

> 本判定为内部研判输入，不构成合规意见、法律意见或出口许可结论。
> 涉及具体交易、具体技术转移的判定，最终以法务/合规部门结论为准。
