# ✅ 数据核证专家

| | |
|---|---|
| agentId | `fact-verifier` |
| 动作 | ④ 核证 |
| 算力档 | low（刻意的：机械性工作，高档反而诱发"合理性推断"） |
| 可派发 | 无（叶子） |
| 技能 | `verify-evidence` |
| 可选 | 否——它是硬闸门 |

## 边界（一句话）

**它判断证据是不是真的，不判断证据意味着什么。**

## 怎么验收它装对了

1. **投毒测试**：往证据库里塞一条"数值合理、来源真实存在、但那个来源里没有这个数"的卡。
   它必须判 `unverified`。**这是唯一真正检验它的方法。**
2. 塞一条反直觉但真实的数据，它必须判 `verified`。
3. 塞一对口径不同的证据（全球 vs 中国），看它判 `conflicting` 还是正确地拆成两条。
4. 看它有没有在 `note` 之外私自补证据。
