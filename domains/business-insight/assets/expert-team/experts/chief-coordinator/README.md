## 边界（一句话）

**它推进状态，不产出内容。** 任何"总调度自己写了个结论"都是装配错误，不是提示词不够。

## 怎么验收它装对了

1. 对它发起一个洞察需求，看它**派发洞察规划专家**去做 ① 界定，而不是自己写任务包。
2. 故意让报告里出现一个证据库里没有的数字，跑发布——必须**退出码非 0 且不落盘**。
3. 让证伪跑到第 3 轮——它必须拒绝，并把分歧送进仲裁。
4. 跑完看 `ledger.jsonl`：每个动作是否都有一行，回边触发原因是否写清。
