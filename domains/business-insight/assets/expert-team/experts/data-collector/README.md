# 🔍 数据采集专家

| | |
|---|---|
| agentId | `data-collector` |
| 动作 | ③ 取证 |
| 算力档 | low |
| 可派发 | **随平台变**（OpenClaw 可；dsh 不可，名册扁平） |
| 技能 | `collect-evidence` |
| 可选 | 否 |

## 边界（一句话）

**它把外面的事实搬进证据库，一个判断都不带。**

## 怎么验收它装对了

1. 随机抽 10 条证据卡，**按 locator 回源**。回不去的比例就是它的编造率——目标是 0。
2. 给它一个公开渠道确实取不到的指标，看它写 `not_found` 还是给了个数。
   **给了数就是没装对**，无论那个数看起来多合理。
3. 看有没有 D 级来源的数字进了表。
4. 看 `conflicting` 有没有被它私自消解成一条。
