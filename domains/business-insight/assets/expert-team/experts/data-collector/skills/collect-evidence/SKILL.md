# 定向取证

## 六步（逐指标执行）

1. **确定要取的是什么**：指标定义、口径范围、期间、单位。
   **口径不明确不要开始取——去问，别猜。**
2. **按等级优先级检索**：A → B → C。找到 A/B 级就停。
3. **摘录原文**（`verbatim`），**不要转述**。转述会丢口径限定词。
4. **记录可定位的 locator**：页码 / 表号 / 章节 / 条目号。
   **填不出 locator 就等于没找到**，写 `unverified`。
5. **原始值与换算值分开记**：`raw` 存来源里的原始表述，`normalized` 存换算后的数，
   换算规则（含汇率与汇率日期）写进 `note`。
6. **找不到就写 `not_found` 并结束这一项。**

## 证据等级

> 实例清单以 `brief.evidencePolicy.grades` 为准。下表是产业类任务包的典型划分。

| 等级 | 来源类型 | 可用性 |
|---|---|---|
| **A** | 官方统计、海关、上市公司年报/招股说明书、政府规划与目录文件、专利数据库 | 直接可用 |
| **B** | 行业协会与标准组织的公开数据、权威行业年鉴 | 直接可用 |
| **C** | 券商研究、第三方咨询报告 | **必须有 ≥1 条独立交叉来源**，注明机构与发布日期 |
| **D** | 媒体报道、厂商宣传、社区讨论 | **永不入表**。只能作为线索，去追它引用的 A/B 级原始来源 |

工具/软件类任务包的等价划分：A = 官方文档与源码与官方 changelog；
B = 可复现的第三方基准与实测记录；C = 分析师评测与对比文章；D = 社媒与营销页。

**D 级材料里出现的数字，追到原始来源之前一律不记。** 二手转述是数字失真的主要来源。

## 口径陷阱（真实会犯的错，逐条自检）

| 陷阱 | 后果 |
|---|---|
| **全球 vs 中国大陆** | 同一指标两个口径能差好几倍。必须在 `scope` 里写死 |
| **行业规模 vs 设备/产品市场规模** | 终端行业 1000 亿 ≠ 设备市场 1000 亿。搞混会让整个市场维度失真 |
| **历史值 vs 预测值** | `2024-2030E` 是预测不是事实。必须在 `period` 里标出 E |
| **口径年份错位** | 拿三年前的份额和今年的规模放一起推算，结论无效 |
| **公司口径 vs 产品线口径** | 上市公司整体毛利率 ≠ 该产品线毛利率。分部披露才是要的 |
| **单位与汇率** | 亿元 / 亿美元 / 百万美元。换算必须记录汇率与汇率日期 |
| **版本错位**（工具类） | 某能力在 v3 才有，而基准跑的是 v2。必须记版本号与测试日期 |

## 冲突的记法

多个来源给出不一致的数值 → **全部记下来**，标 `conflicting`，
在 `conflict_with` 里互相引用。

**不要挑一个"更可信的"，不要平均。** 那是核证与仲裁的工作。

如果不一致源于**口径不同**（一个全球一个中国），这不是冲突——
它是两条不同的证据，分别拆开记录并修正各自的 `scope`。

## 发现新对象怎么办

取证途中发现枚举没覆盖的对象：
**写进产出报回总调度（触发回边 R1），不要自行并入。**
新对象需要走一遍闸门；自行并入会绕过闸门，而且没人会发现。
