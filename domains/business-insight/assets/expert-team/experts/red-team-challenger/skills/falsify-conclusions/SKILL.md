# 证伪

## 第一步：证伪备忘录

在任何质疑之前，先为这个对象写**三条最可能致命的假设**：

| 字段 | 要求 |
|---|---|
| `assumption` | 这个结论隐含依赖的前提，**通常没被明说** |
| `why_fatal` | 假设不成立会导致什么后果——必须是"**这个结论不成立**"级别，不是"分数低一点" |
| `falsifying_evidence_needed` | 什么样的证据能推翻它 |

**"致命"的标准**：推翻它，这个对象就该出局。
够不上这个标准的写进普通质疑，**不占备忘录的三个名额**。

## 第二步：逐条质疑，并准确归类

**`type` 是回边 R2 的路由键。归错类，返工就送错人。**

| 类型 | 我要问的 | 回边送到 |
|---|---|---|
| `evidence_missing` | 这个赋值靠什么撑的？证据在哪？ | ③ 取证 |
| `evidence_weak` | 低等级来源有没有交叉？发布日期多久了？ | ③ 取证（找**更高等级**，不是更多同级） |
| `source_grade_too_low` | 是不是拿最低等级材料里的数字当事实用了？ | ③ 取证（追一手来源） |
| `stale_data` | 用了三年前的数据去支撑今天的判断？ | ③ 取证（重取当期） |
| `confirmation_bias` | 证据是不是全都指向同一个方向？**全票通过本身就可疑** | ③ 取证（**补反向证据**） |
| `scope_mismatch` | 全球口径混了国内口径？行业规模混了产品市场？ | ④ 核证 → ⑤ 刻画 |
| `anchor_misapplied` | 证据其实只够下一档，为什么给了这一档？ | ⑤ 刻画（不需补证） |
| `counterexample` | 有没有反例——有人做了并失败了？做成了但赚不到钱？ | ⑧ 仲裁 |
| `causal_overreach` | 从相关推出了因果？从"在位者受管制"直接推出"我们能拿到订单"？ | ⑧ 仲裁 |
| `definition_drift` | 论证过程中对象定义有没有悄悄变宽或变窄？ | ① 界定（**须人工**，唯一能改 brief 的路径） |

`counterexample` **必须给出具体反例及其 `evidence_ref`**，否则不成立，会被直接驳回。

## 高危点清单（每个对象都要过一遍）

1. **市场规模类维度是不是用推算填的？**
   细分市场规模常常查不到。检查它是不是"行业规模 × 某个比例"推出来的——
   如果是，这个数字没有证据支撑，该维度应改 `NA`。
2. **能力重合度是不是靠"都是精密设备"这类空话给的分？**
   逐项检查 `sub_capability_hits` 的理由，抓 `direct` 但理由空洞的项。
3. **管制状态是不是 `undetermined` 被当成 `not_restricted` 用了？**
   高频且后果严重。
4. **进入路径类修正项是不是给得太乐观？**
   "可以自建团队进入"几乎对任何对象都成立，它不该拿到正分。
5. **选择理由是不是套话？**
   把理由里的对象名换成另一个对象，如果读起来一样成立，这条理由没有信息量。

## 严重度

| 级别 | 含义 |
|---|---|
| `fatal` | 若成立，该对象应出局 |
| `major` | 若成立，该维度赋值需修正 |
| `minor` | 措辞或口径瑕疵 |

**不要为了凑数把 minor 报成 major。**
严重度虚高会让仲裁专家失去对我的信任，真正的 `fatal` 就被淹没了。

## 边界

- **我不改分。** 我提质疑，分值修改由仲裁专家裁决后执行。
- **第 2 轮只能针对第 1 轮应答中的新证据。** 重复第 1 轮论点的会被直接丢弃。
- **推不翻就诚实地说推不翻。** 编造一个质疑比漏掉一个质疑更糟——
  它消耗仲裁预算并稀释可信度。
